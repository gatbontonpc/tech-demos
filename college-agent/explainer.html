Waypoint · how the admissions agent is put together

Why the Sunday memo can be trusted

College admissions is a fifteen-month file, not a conversation. A sixteen-year-old cannot be expected to know which fact about themselves would move a list, so an empty text box is the wrong front door. Waypoint reads the record, stores claims with their sources, asks the three questions that would actually change the schools, and reports once a week. This page is why each of those pieces is shaped the way it is.

The student in the diagrams is Avery Chen of Northline High, class of 2027. Fictional The schools and the dollar figures are invented. The mechanisms are the ones in the prototype.

1. Three connectors, because the permissions are not the same thing

A single “connect Google” button would be easier to draw and worse to explain. Gmail and Drive are search problems. The app is allowed to look for transcripts, score reports, activity mail, and essays, and it is not allowed to send, delete, or share anything. Google Photos is not a search problem. An app that asked for the photo library would be able to see the whole camera roll, which is the wrong permission for “show me the Science Olympiad medal.” The Photos Picker API exists so the app can read only the items a person picks.

Gmail and Drive can be queried. Photos cannot. The dashed box is the residual, not the front door.

The Picker flow is a session, not a scope that quietly widens later. The app calls sessions.create on photospicker.googleapis.com, gets back an id and a pickerUri, and opens that URI in a new tab. Appending /autoclose closes the tab when the person hits Done. The app then polls sessions.get on the interval in pollingConfig.pollInterval until mediaItemsSet is true or timeoutIn runs out. Only then does mediaItems.list return the picked files. If mediaItemsSet stays false, there is nothing to download, which is the point: no selection means no photos.

Upload slots are the same rule applied to documents. They appear after a search finishes empty. They do not appear on the first screen, because a drop zone would teach the family to assemble a packet by hand, which is the job the connectors just took. In the demo, Gmail and Drive fixtures find the transcript, the SAT mail, the activities doc, and the essay. They do not find a photo of the medal or a senior fall grade report, so those two slots open and nothing else does.

Demo mode is a different door, painted as one. It loads Avery’s fixtures and labels every connector “Fixture.” It does not call Google, and it does not flip a connector to “Connected as you@gmail.com.” If the client ID is missing, the real buttons still run and then stop with the error. A silent fallback would make a broken OAuth client look like a successful login, and then every provenance tag on the dossier would be a lie.

2. The pipeline writes claims, and every claim wears its source

A chat transcript is a bad place to keep a GPA. The number is buried in a turn, it has no date, and when a new score arrives you cannot diff it against last week. Waypoint stores a claim: a field, a value, the file it came from, how sure the extraction was, and whether a person has confirmed it. The dossier, the portfolio, the memo, and the counselor roster all read that same object. When Avery fixes the intended major, the old Drive tag stays on the card. The correction is marked “Fixed by you.” The source and the edit are different facts, and both have to remain visible or the family cannot audit the line.

The matcher in this prototype keys off subject lines and file names. A later parser can fill the value. It should not get to throw away the tag.

Here is Avery’s GPA as stored. Everything in it is made up.

{
  "id": "gpa",
  "value": "3.82 unweighted. 9th 3.61, 10th 3.74, 11th 3.96.",
  "provenance": {
    "source": "Gmail",
    "detail": "Official transcript — Northline High",
    "when": "Sep 15, 2026",
    "confidence": "high"
  },
  "status": "unreviewed"
}

Confidence is a property of the extraction, not a vibe. The GPA is high because the transcript mail and the Drive PDF agree on the file, and the demo fixture already contains the parsed number. The intended major is medium because no sentence in the file says “mechanical engineering.” The robotics captaincy and the AP mix imply it. That is a different kind of uncertainty from “we only have 64 example self-reports for Ridgeview,” and the tags are written so a parent can tell them apart.

The live path is narrower on purpose. With a real client ID, Gmail’s users.messages.list runs a handful of read-only queries (transcript, score report, activity, award, essay, fall grades), then messages.get with format=metadata so the app stores subject, from, and date rather than the message body. Drive’s files.list does the same with file names. The claim text then says a file matched and that this build did not read a number out of the PDF. Shipping a confident GPA from a filename would be worse than shipping a low-confidence claim the student has to type.

3. Rank the unknowns by how far the list would move

An interview of forty questions fails for a mechanical reason. Most of the answers do not change which schools are on the list, and the student can feel that, so they stop answering. The replacement is a sort. Each unknown gets a decision impact: how many schools enter, leave, or change zone if the answer flips. Keep the top three. Throw the rest out of the first session.

Bar length is the count of schools the answer would move. The faded questions are real preferences. They are not first.

The West Coast question is first because five of the nine schools in the working set are outside the region: Lakemont, which is already on the list, plus Redcedar, Kingsmill, Easton, and Northwater, which are not. Lakemont is the only reach. “West Coast only” removes the reach and leaves a 0–2–2–1 balance, which the portfolio says out loud as “thin on reach.” “Yes, I’ll leave” keeps Lakemont and does not silently add the other four. They stay candidates until a decision card says otherwise. That split matters. A preference the student just confirmed can change the list. A tier change the agent noticed in new admit data cannot, not until Approve, Keep plan, or Ask counselor.

The cost question is second because the example bands are already numbers. Lakemont is $31–38k. Harbor Tech is $22–29k. A ceiling near $25k puts one school above the plan and one on the edge. A ceiling near $15k leaves Sierra Pacific as the only school fully inside it. Without a ceiling, every cost tag is a range with nothing to compare it to, so “no ceiling yet” is an allowed answer and it lowers confidence instead of inventing a number.

The co-op question is third because it is the only reason Tidewater is a card at all. Harbor Tech and Tidewater both require a co-op. Tidewater is not on the list. If co-op is a must-have, Sunday’s memo has a real decision: add a target under the ceiling that is farther from Northline than anything else. If co-op is merely nice, that card can wait. Asking “tell me about your activities” would have felt relevant and would not have changed a single zone.

Skip is a button on each question, and it is not a trap. Two skips drop list confidence to low and widen every range by four points on the zone strip. The portfolio still opens. A blocked screen would punish the student for not knowing yet, which is how the forty-question interview loses them.

4. The week is a loop that ends in two memos

The dossier is how the agent gets a model on day one. It is not a reason to come back in November. The reason to come back is that deadlines, portal mail, aid bands, and admit profiles change while the family is doing something else. The loop is: jobs run, diffs are written, two memos are drafted, a person clears the cards that would change the list, and next week’s jobs read the updated claims.

The dashed arrow is the product. A memo that cannot change next week’s jobs is a newsletter.

Two copies, because the readers are stuck on different sentences. Avery needs “Harbor Tech Early Action closes November 1, the supplement is 392 words, one recommender is still open.” A parent needs “Cascade’s example net price moved to $15–19k, Lakemont is still $31–38k, and 7 of 9 schools still fit a $25k ceiling.” Same underlying diffs. The parent copy does not hide the deadline. It just refuses to lead with a word count.

Anything that would move a tier or add a school is a card with three buttons, not a paragraph that already did it. Ridgeview’s October admit profile, a thin one at n=64, would place Avery in stretch. The portfolio keeps the target badge and prints the proposal as a flag until Approve. Keep plan leaves the badge and records that the profile was seen and declined. Ask counselor puts the family on the roster’s waiting column and still does not move the school. The agent is allowed to be wrong in a memo. It is not allowed to be wrong inside the list.

The jobs are listed beside the memo, fourteen of them, including the ones that found nothing: no fall grade file, no aid letter, scholarship X already closed. A background agent that only reports hits looks like it is selling. One that reports the empty searches is checkable. Past memos sit under the current one, three weeks of them, so Sunday does not feel like a first run. Week 35 was the dossier. Week 36 was the Sierra Pacific add, which went through a card. Week 37 had a new SAT on file and zero decisions. That is the shape of a quiet week, and the product has to be willing to send it.

What this build deliberately does not do

There is no message box, on the family screens or on the counselor roster. There is no live College Scorecard call. The bands are example numbers with source tags that say so. There is no PDF parser and no model reading an essay. There is no cron server. The weekly loop in the demo is a fixture of jobs, diffs, and history, wired to the same buttons the live claims use. OAuth, the Gmail and Drive searches, and the Photos Picker session are the real clients. They run only when a client ID is present, and they fail in the open when it is not.

Open the app, load the fictional fixtures, and walk Sources, Dossier, the three questions, the portfolio, both memos, and the optional roster. The explainer is this file. It does not need a build.
